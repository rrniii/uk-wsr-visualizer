## Shared example

The user-facing examples use Castor Bay on 18 September 2014, long pulse at
15:35 UTC. This source volume is small enough for a quick walkthrough and
contains Horizontal Reflectivity (DBZH), Horizontal Radial Velocity (VRADH),
Horizontal Spectrum Width (WRADH), Differential Reflectivity (ZDR), Copolar
Correlation Coefficient (RHOHV), Differential Phase (PHIDP), Signal Quality
Index (SQIH), and CI across five elevations.

The goal is reproducibility, not a scientific interpretation of the event.
Start with cleanup off and treat the plotted echoes as material for inspection.
